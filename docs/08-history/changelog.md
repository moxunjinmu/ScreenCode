# ScreenCode 变更日志

> 最后更新：2026-09-07

---

## 1.1.8 - 2026-09-07

### 修复与简化
- 采集卡只使用精确协议，移除“采集方式/浏览器自动”选择；只保存最后使用的一套设备、格式、分辨率和 FPS
- 设置页隐藏仅对旧浏览器采集生效的“默认预览策略”，保留截图与 AI 图片质量选择
- 启动先展示 D 盘缓存的采集参数，探测完成后自动应用；临时错误保留选择并提供重试
- 修复探测期间点击设备覆盖缓存、设备名称未返回时恢复失败，以及设置页旧配置反向覆盖采集参数
- 使用 Radix Select 替换自建下拉框，修复嵌套弹层的遮挡和焦点交互
- 增加真实浏览器回归：缓存恢复、自动连接、参数选择、键盘操作和重启恢复

## 1.1.7 - 2026-09-07

### 新功能
- 将顶部工具栏收敛为设备、采集参数、分辨率和高频操作，协议与显示设置按需展开
- 采用 Radix Popover 提供开源的浮层定位、焦点管理、碰撞处理和键盘关闭能力

### 修复
- 移除顶部重复的 FPS、H264/VP8、验证状态和协议摘要，只保留当前分辨率
- 紧凑视口使用图标化操作，不再依赖横向滚动查看工具栏功能

---

## 1.1.6 - 2026-09-07

### 新功能
- 将采集卡设备、精确协议、格式、分辨率和帧率按设备保存到 `D:\ProgramData\ScreenCode`
- 浏览器或驱动导致设备 ID 变化时，按规范化设备名恢复上次通道并自动连接预览
- 首次启动自动迁移旧采集配置，且采集缓存不包含供应商密钥

### 修复
- 修正包含精确协议缓存的新安装包仍显示为 `1.1.5` 的版本漂移问题

## 2026-04-17

### 区域截图二次编辑
- 区域截图选择后进入编辑模式，显示红色边框和 8 个手柄（四角 + 四边中点）
- 支持拖拽边框调整选区大小（8 方向：上/下/左/右/四角）
- 支持拖拽选区内部移动整个选区
- 鼠标悬停边框自动切换对应方向的 resize 光标
- 新增"重截"按钮：调整选区后可重新截取新区域
- ✓ 确认保存 / ✕ 取消退出
- 选区外点击可重新开始新选区

### 截图确认流程
- 区域截图选择完成后不再直接保存，显示 ✓/✕ 确认按钮
- 点击 ✓ 后才执行保存到帧队列和剪贴板
- 点击 ✕ 取消并退出区域截图模式

## 2026-04-08

### 显示分辨率调整
- Preview 组件新增分辨率选择器（源分辨率 + 预设分辨率 + 百分比缩放）

- 预设缩放比例：50%, 75%, 100%, 125%, 150%, 200%
- 自动检测视频源最大分辨率作为默认选项
- AppConfig 新增 `displayResolution` 字段支持持久化

### 聊天面板默认状态
- 默认关闭右侧 AI 对话面板（isChatPanelOpen 默认值改为 false）
