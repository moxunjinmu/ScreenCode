# 环境要求

> 最后更新: 2026-02-28

## 运行时依赖

| 依赖 | 版本 | 说明 |
|------|------|------|
| Node.js | ^18 | 运行时 |
| npm | ^9 | 包管理 |
| Electron | ^28 | 桌面框架 |

## 系统要求

| 平台 | 支持状态 |
|------|----------|
| Windows 10+ | 主要目标平台 |
| macOS | 开发环境支持 |
| Linux | 未测试 |

## Native 模块

| 模块 | 用途 | 安装注意 |
|------|------|----------|
| Sharp | 图像压缩 | 需要 C++ 编译工具链（Windows: Visual Studio Build Tools） |

## 外部服务

| 服务 | 用途 | 必需 |
|------|------|------|
| Anthropic API | Claude AI 调用 | 至少配置一个供应商 |
| 智谱 AI API | GLM-5 调用 | 可选 |
| OpenRouter API | 多模型路由 | 可选 |

## 硬件要求

| 设备 | 用途 | 必需 |
|------|------|------|
| USB 采集卡 | 捕获内网屏幕 | 核心功能必需 |
| HDMI 线缆 | 连接内网机器 | 核心功能必需 |
